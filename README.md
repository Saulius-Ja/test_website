# NordicPulse Manufacturing — test website

Static one-page website for a fictional single-factory EMS (electronics manufacturing services) company. Built for test purposes only.

## Structure

```
index.html          page markup and content
styles.css          all styling (colour tokens at the top under :root)
script.js           mobile menu toggle
assets/logo-mark.svg  logo and favicon
assets/img/*.svg      illustration placeholders, replace with real photos as needed
```

No build step and no dependencies apart from Google Fonts (Fraunces, Inter, IBM Plex Mono).

## Run locally

Open `index.html` in a browser.

## Publish on GitHub Pages

1. Push this folder to a GitHub repository.
2. Go to **Settings → Pages**, set **Source** to *Deploy from a branch*, choose `main` and `/ (root)`.
3. The site appears at `https://<user>.github.io/<repo>/`.

## Content note

All company facts (location, figures, certifications, news, case study, addresses) are invented placeholders.
